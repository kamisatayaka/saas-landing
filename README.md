# CopyCraft AI — SaaS Landing Page

A polished, conversion-focused marketing landing page for **CopyCraft AI**, a fictional AI marketing-copywriting SaaS. Built as a portfolio/showcase project in **React + Vite**.

## Sections included

- Sticky navbar with brand logo
- Hero with value prop, CTAs, and a CSS product-screenshot mock
- Social-proof logo strip
- 6-feature grid
- "How it works" 3-step section
- Testimonials
- 3-tier pricing (with "Most popular" highlight)
- FAQ accordion
- Final call-to-action band
- Footer

## Run locally

```bash
npm install
npm run dev      # dev server with HMR
npm run build    # production build -> dist/
npm run preview  # preview the production build
```

## Tech stack

- **React 19** + **Vite** (fast dev/HMR)
- Pure CSS with a modern design system (custom properties, gradient brand), responsive breakpoints
- No UI framework — easy to understand and extend, ideal as a first portfolio piece

## Portfolio / client notes

This project is designed to sit in a `GitHub` repo and deploy free to **Netlify** or **Vercel** with zero server setup (they auto-detect Vite). It demonstrates: clean component structure, responsive design, accessibility (semantic HTML, aria labels), and a real production build — all things clients look for in a landing-page deliverable.
